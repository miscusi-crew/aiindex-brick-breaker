# Brick Breaker

Bounce the ball, break every brick, don't let it drop.

Keep the ball in play with your paddle and clear every brick. Each level is a little faster.

- **Move:** mouse, touch, or arrow keys
- **Launch / pause:** Space, click or tap
- Three lives per game; your best score is saved

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
